# ZMO AI Pipelines (deprecated)

> [!IMPORTANT]
> This project is no longer maintained. Use **[Kalamu](https://github.com/fmadore/Kalamu)** instead.

Kalamu is a desktop app for researchers on Windows and macOS. It reads scanned and
handwritten documents, transcribes interviews and analyses texts with Gemini,
OpenAI, Claude or Mistral, or offline with Whisper, and checks every result
against its source. No Google Colab or Python needed.

**→ [Get Kalamu](https://github.com/fmadore/Kalamu)**

The Colab notebooks that used to live here now only point to Kalamu. The code and
documentation remain in the history for reference; the previous README is kept in
[docs/legacy-README.md](docs/legacy-README.md).
